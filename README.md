# Linked Lists in C++

## Description

A console program that implements three linked list types from scratch in C++, with a menu to try every operation.

| List | File | Operations |
| --- | --- | --- |
| Singly linked list | `single_linklist.cpp` | add front / end / at position / sorted, search, count, delete node, delete all, display |
| Doubly linked list | `doubly_linklist.cpp` | the same, plus display in reverse |
| Circular linked list | `Circular_linklist.cpp` | add front / end / after value, delete front / end / value, delete all, display |

Each list frees all of its nodes in its destructor.

## Instructions

```bash
make
./my_program
```

Requires `g++` with C++11.
